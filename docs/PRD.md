# PRD: Koma 本地漫画阅读器

## 1. 产品定位

Koma 是一个基于 Electron + React + TypeScript 的本地优先桌面漫画阅读 App，面向个人本地漫画收藏管理与阅读。

用户可以将本地漫画文件夹导入书库，在书库中浏览漫画，点击后进入沉浸式阅读器。阅读器支持竖向滚动、单页阅读、适应宽度、缩放、背景色切换、全屏和阅读进度记忆。

第一版重点是：本地、简单、流畅、好读。

## 2. 目标用户

主要用户是开发者本人，也可以服务于有本地漫画文件夹收藏习惯的用户。后续可能开源到 GitHub。

典型场景：

- 本地有多个漫画文件夹。
- 每个漫画文件夹内包含多张图片。
- 希望统一导入、展示封面、记住进度。
- 希望阅读时界面简单，专注看图。

## 3. MVP 范围

支持：

- 本地文件夹漫画。
- 书库导入。
- 临时打开文件夹。
- 竖向滚动阅读。
- 单页图片显示。
- 从左到右文件顺序。
- 适应宽度。
- 全屏。
- 缩放。
- 背景色切换。
- 自动保存阅读进度。
- 前后页预加载。

暂不支持：

- .cbz / .zip / .rar / .pdf。
- 在线漫画源。
- 日漫从右到左。
- 双页模式。
- 自动裁白边。
- 图片增强。
- 标签系统。
- 云同步。
- 账号系统。

## 4. 技术栈

- Electron: 桌面壳、本地文件访问、窗口控制、IPC。
- React: Renderer UI。
- TypeScript: 类型约束。
- SQLite: 书库、页面、进度。
- electron-store: 阅读偏好、窗口轻量配置。

## 5. 信息架构

- 书库页：漫画列表、导入、临时打开、搜索、阅读进度。
- 阅读器页：竖向滚动图片、缩放、背景色、全屏、进度保存。
- 设置能力：MVP 内嵌在阅读器工具栏，后续可独立设置页。

## 6. 书库页

书库页展示已导入漫画，支持导入本地漫画文件夹、临时打开文件夹、继续阅读、搜索漫画标题。

漫画卡片展示：

- 封面：文件夹内第一张图片。
- 标题：默认使用文件夹名。
- 页数：识别到的图片数量。
- 进度：已读页数 / 总页数。
- 状态：未读 / 阅读中 / 已读。

删除书库记录时不删除本地文件。

## 7. 文件夹导入

导入流程：

1. Electron 打开系统文件夹选择器。
2. 用户选择一个漫画文件夹。
3. App 扫描该文件夹内图片。
4. 按文件名自然排序。
5. 生成漫画记录。
6. 使用第一张图片作为封面。
7. 保存到 SQLite。

支持图片格式：jpg、jpeg、png、webp、gif、avif。

重复导入相同路径时，复用现有记录并打开该漫画。

## 8. 临时打开文件夹

用户可以直接选择一个文件夹阅读，不强制加入书库。临时漫画可以阅读，但不写入书库列表。后续可增加“加入书库”。

## 9. 阅读器

阅读模式：

- 竖向滚动。
- 单页图片。
- 从上到下阅读。
- 从左到右文件顺序。
- 默认适应宽度。

功能：

- 鼠标滚轮滚动阅读。
- 图片缩放：适应宽度、100%、125%、150%。
- 背景色：黑、深灰、浅灰、白。
- 全屏切换。
- 当前页识别。
- 自动保存阅读进度。
- 预加载当前页前 2 页、后 3 页。

快捷键：

- Esc：退出全屏或返回书库。
- F：切换全屏。
- +：放大。
- -：缩小。
- 0：恢复适应宽度。
- Home：回到第一页。
- End：跳到最后一页。

## 11. 验收标准

- 用户可以导入一个本地漫画文件夹。
- App 能识别文件夹内图片，并按自然顺序展示。
- 书库页能显示漫画封面、标题、页数、阅读进度。
- 点击漫画可以进入阅读器。
- 阅读器以竖向滚动方式展示所有图片。
- 图片默认适应宽度。
- 用户可以缩放图片。
- 用户可以切换背景色。
- 用户可以进入全屏阅读。
- App 会自动保存阅读进度。
- 重新打开漫画时能回到上次阅读位置。
- 前后页有预加载，连续滚动不明显白屏。
- 用户可以从书库移除漫画记录，但不会删除本地文件。
